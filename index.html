О программе

PalaDin — музыкальный язык программирования, созданный для того, чтобы превратить код в музыку.

Проект разработан одним человеком как эксперимент на стыке программирования и музыки. Язык основан на стековой модели, использует ноты вместо чисел и позволяет создавать композиции в реальном времени.

Особенности языка:

  • 7 нот (q w e r t y u) и 8 октав (1-8)
  • Более 30 жанров с уникальными эффектами (от Ambient до Dubstep)
  • Управляющие конструкции: функции (def), условия (if-else), циклы (loop)
  • Стековые операции: + - * / dup drop swap over rot ++ -- store fetch sin cos sqrt abs wait vol
  • Встроенный справочник и примеры
  • Экспорт в MP3 через Web Audio API

Социальные функции:

  • Сохранение мелодий, лайки, рейтинг
  • Поиск по названию/автору/жанру
  • Чаты с модерацией (мат-фильтр, предупреждения, автобан)
  • Лента с постами, фото, музыкой и комментариями
  • Админ-панель для управления пользователями и сообщениями

Технические детали:

  • Данные хранятся в IndexedDB (и localStorage для сессии)
  • Звук генерируется через Web Audio API, работает в Chrome и Firefox
  • Полностью адаптивный дизайн (десктоп + мобильная нижняя панель)
  • Кастомные модальные окна вместо системных диалогов

Пользовательское соглашение

Настоящее соглашение регулирует использование приложения PalaDin. Используя приложение, вы соглашаетесь с условиями:

1. Общие положения
PalaDin предоставляется «как есть» без каких-либо гарантий. Разработчик не несёт ответственности за возможный ущерб, возникший в результате использования приложения.

2. Данные пользователя
Приложение хранит логин, пароль (в зашифрованном виде), созданные мелодии, лайки и сообщения в локальном хранилище вашего браузера. Эти данные не передаются третьим лицам и используются только для работы приложения.

3. Файлы cookie
Приложение не использует сторонние файлы cookie, но использует localStorage для хранения данных сессии. Это необходимо для авторизации и сохранения настроек.

4. Ответственность
Пользователь сам отвечает за сохранность своих данных. Рекомендуется регулярно делать резервные копии.

5. Согласие с условиями
